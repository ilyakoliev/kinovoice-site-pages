Карточки для соцсетей

Пост 1080×1350 — для ленты ВКонтакте, MAX, Threads* и Instagram*. Сторис 1080×1920: всё важное в безопасной зоне, под цитатой пунктиром размечено место для стикера-ссылки на текст.

Карточки обновляются при каждой выкладке: тексты, которые вышли или дополнились новым разделом за последние 60 дней, и старые из списка data/share-kit.json. Карточки любого другого текста: npm run share:cards -- slug. Служебная страница: её нет в меню, в карте сайта и в поиске.
